# Documentación de RestoBA

Guía web para descubrir restaurantes: el comensal encuentra locales cercanos, ve la carta, llega,
reserva, reseña y suma puntos; los restaurantes pagan una suscripción mensual para aparecer.

> [!IMPORTANT]
> **Alcance del proyecto:** llega hasta el comensal que va al restaurante y el restaurante que paga
> para aparecer en la guía. La gestión interna del local (mozos, cocina, pedidos, cobro e
> inventario) queda fuera de alcance.
